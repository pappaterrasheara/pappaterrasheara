# Hello, I'm Sheara 🌌

I write code to figure out how rockets get up there, stay up there, and come back in one piece.

I'm studying mechanical engineering at Northeastern University. Most of my projects start with a question like "how much Δv does this really take?" and end with a script that answers it. I'm always down to talk propulsion, orbital mechanics, or RK4 integration.

Long term, I want to work on reusable heat shields. Getting a spacecraft like Starship through re-entry is one thing. Flying it again quickly, without a ton of inspections and repairs in between, is still one of the hardest problems in spaceflight, and I'd love to help crack it.

## Things I've built

### Getting up there

- **[Orbital-X](https://github.com/pappaterrasheara/Orbital-X)** (Python): Simulates a supersonic rocket's vertical flight with RK4 integration. It models thrust, mass loss, drag, and the atmosphere, then saves the flight data to CSV and plots it.
- **[Mission Planning for a Supersonic Rocket](https://github.com/pappaterrasheara/Mission-Planning-for-a-Super-Sonic-Rocket)** (Python): Another RK4 flight sim, this one focused on tracking altitude, velocity, and Mach number, with CSV export and plots.
- **[Thrust Calculator](https://github.com/pappaterrasheara/Thrust-Calculator)** (Python): Works out engine thrust from mass flow rate and exhaust velocity.
- **[ISP & Propellant Calculator](https://github.com/pappaterrasheara/ISP-Propellant-Calculator)** (Python): Finds specific impulse and how much propellant you need, based on thrust, burn time, and exhaust velocity.

### Staying up there

- **[Orbital Insertion Suite](https://github.com/pappaterrasheara/orbital-insertion-suite)** (Python): Tools for orbital insertion, the burn that actually puts a spacecraft into orbit.
- **[Inclination Δv Calculator](https://github.com/pappaterrasheara/Inclination-dv-Calculator)** (Python): Figures out how much Δv it takes to tilt a spacecraft's orbit to a new inclination.

### Coming back in one piece

- **[Ablative Shield Calculator](https://github.com/pappaterrasheara/Ablative-Shield-Calculator)** (Python): Estimates how thick a heat shield needs to be and how fast it burns away during re-entry.

### A bit of everything

- **[AeroForms-X Calculator](https://github.com/pappaterrasheara/AeroForms-X-Calculator)** (MATLAB): A modular calculator with a form-based interface that covers the core equations of aerodynamics, propulsion, and orbital mechanics.
